# Kisshyendravel Kumaravel — Portfolio Website

A responsive personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `kisshyendravel.github.io` (or choose any repository name).
2. Upload the contents of this folder to the repository root. Make sure `index.html`, `style.css`, `script.js`, `resume.pdf`, and `assets/` are at the top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. GitHub will display your live website URL in Settings → Pages.

If you use the repository name `kisshyendravel.github.io`, the expected URL is `https://kisshyendravel.github.io/` once that repository is created under the matching GitHub username. If your GitHub username is different, replace `kisshyendravel` in the repository name and URL.

## Update your details
Edit `index.html` to update text, links, education, projects or experience. Replace `assets/profile.jpg` to change the portrait. Replace `resume.pdf` to update the downloadable CV.

## Notes
- The site uses no build tools or external JavaScript libraries.
- Google Fonts is loaded online; the page still works with system font fallbacks if unavailable.
- Contact details are taken from the supplied resume.
- The website content is based on the supplied one-page resume. Confirm any new employment or internship details before adding them.
